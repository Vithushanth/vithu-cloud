Visitor counter API

A small API that this site calls on every visit. The total in the footer of this page comes from it.

Built with
API Gateway (HTTP API), Lambda (Python 3.12), DynamoDB, AWS SAM
View the code on GitHub

How it works

  1. When a page loads, the site sends POST /hit to the API once per browser session.
  2. API Gateway checks the request against its CORS and throttling settings, then invokes the Lambda function.
  3. The function runs one DynamoDB update that adds one to the counter and returns the new value.
  4. The site shows the total in the footer. If the API does not answer, the footer simply shows nothing.

Why I built it

My other projects can only be read about. I wanted one that visitors can see working.

What I learned

  • DynamoDB's ADD is atomic, so two visits at the same moment are both counted. Reading the value and writing it back would lose one.
  • An HTTP API is cheaper and simpler than a REST API when all it does is call a function.
  • Throttling is a cost control. The API allows 2 requests a second, so nobody can run up a bill.

One atomic update

result = table.update_item(
    Key={"id": "site"},
    UpdateExpression="ADD visits :one",
    ExpressionAttributeValues={":one": 1},
    ReturnValues="UPDATED_NEW",
)
visits = int(result["Attributes"]["visits"])

The function's role allows one action, dynamodb:UpdateItem, on one table.

What I would add next

  • Unique visitors per day instead of raw page loads
  • A CloudWatch alarm on API errors
  • A custom domain such as api.vithu.cloud

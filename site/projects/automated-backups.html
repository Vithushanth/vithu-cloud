Automated backups and snapshots

Backups that run every night without anyone remembering, and clean up after themselves so storage costs stay flat.

Built with
Lambda (Python 3.12), boto3, EventBridge, EBS, CloudWatch, AWS SAM
View the code on GitHub

How it works

  1. EventBridge triggers the function every day at 02:00 UTC with the rule cron(0 2 * * ? *).
  2. The function finds every EBS volume tagged Backup=true.
  3. It creates a snapshot of each one and tags it with CreatedBy=automated-backup and the date.
  4. It then lists the snapshots carrying that tag and deletes any older than RETENTION_DAYS, which is set to 7.
  5. Each snapshot created or deleted is written to CloudWatch Logs.

Why I built it

Manual backups get forgotten. I wanted a system that protects data on its own and also removes old snapshots, because snapshot costs build up quietly when nobody deletes them.

What I learned

  • How to filter AWS API results by tag, so the function only ever touches resources it is meant to.
  • Tags are what make automation and cost control possible. Opting a volume in is a single tag.
  • How to write automation that is safe to run again and again. The cleanup only deletes snapshots the function created itself.

Deleting only what the function created

def delete_old_snapshots():
    deleted = []
    cutoff = datetime.datetime.now(datetime.timezone.utc) \
        - datetime.timedelta(days=RETENTION_DAYS)
    snapshots = ec2.describe_snapshots(
        OwnerIds=["self"],
        Filters=[{"Name": "tag:CreatedBy",
                  "Values": ["automated-backup"]}],
    )["Snapshots"]

    for snap in snapshots:
        if snap["StartTime"] < cutoff:
            ec2.delete_snapshot(SnapshotId=snap["SnapshotId"])
            deleted.append(snap["SnapshotId"])
    return deleted

To opt a volume in, tag it: aws ec2 create-tags --resources vol-XXXX --tags Key=Backup,Value=true

What I would add next

  • A summary sent to SNS or Slack after each run
  • Copies of snapshots in a second region for disaster recovery
  • AWS Backup in place of the custom code, for managed retention policies
